Лекция 5. Механика

Кафедра общей физики

=== 1. Кинематика ===

Кинематика изучает движение тел, не рассматривая его причины.

Основные величины:
- Перемещение (s) — вектор из начальной в конечную точку
- Скорость (v) — производная перемещения по времени: v = ds/dt
- Ускорение (a) — производная скорости: a = dv/dt

Равномерное движение: s = v · t
Равноускоренное движение: s = v₀·t + a·t²/2
Скорость при равноускоренном движении: v = v₀ + a·t

=== 2. Законы Ньютона ===

Первый закон (закон инерции):
Тело сохраняет состояние покоя или равномерного прямолинейного движения, пока на него не действуют силы.

Второй закон:
Ускорение тела прямо пропорционально действующей силе и обратно пропорционально массе: F = m·a

Третий закон:
Силы, с которыми два тела действуют друг на друга, равны по модулю и противоположны по направлению: F₁₂ = -F₂₁

=== 3. Работа, энергия, мощность ===

Работа силы: A = F·S·cos(α), где α — угол между силой и перемещением.
Единица измерения — джоуль (Дж) = Н·м.

Мощность — работа в единицу времени: P = A/t. Единица — ватт (Вт) = Дж/с.

Виды энергии:
- Кинетическая: Ek = m·v²/2
- Потенциальная (в поле тяготения): Ep = m·g·h
- Потенциальная упругой деформации: Ep = k·x²/2

Закон сохранения энергии: в изолированной системе полная механическая энергия остаётся постоянной, если действуют только консервативные силы.
Ek + Ep = const

=== 4. Импульс ===

Импульс тела: p = m·v. Единица — кг·м/с.

Закон сохранения импульса: в замкнутой системе полный импульс сохраняется.
Σp_до = Σp_после

Применяется при анализе столкновений:
- Абсолютно упругий удар: сохраняются и импульс, и екинетическая энергия
- Абсолютно неупругий удар: тела слипаются, часть энергии переходит в тепло

=== 5. Гравитация ===

Закон всемирного тяготения (Ньютон):
Два тела притягиваются с силой, прямо пропорциональной произведению их масс и обратно пропорциональной квадрату расстояния между ними:
F = G·m₁·m₂/r²

G = 6.67·10⁻¹¹ Н·м²/кг² — гравитационная постоянная.

Первая космическая скорость (для Земли): v₁ ≈ 7.9 км/с — скорость для круговой орбиты у поверхности.
Вторая космическая скорость: v₂ ≈ 11.2 км/с — скорость для преодоления гравитации Земли.

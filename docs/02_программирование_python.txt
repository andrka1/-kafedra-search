Лекция 2. Основы программирования на Python

Кафедра информационных технологий

=== 1. Типы данных ===

Python — высокоуровневый язык с динамической типизацией.

Основные встроенные типы:
- int — целые числа (неограниченного размера)
- float — дробные числа
- str — строка (неизменяемая)
- bool — True или False
- list — список (изменяемый)
- tuple — кортеж (неизменяемый)
- dict — словарь (ключ-значение)
- set — множество (без дубликатов)
- None — отсутствие значения

Переменные объявляются без указания типа: name = "Ivan", age = 20.

=== 2. Управляющие конструкции ===

Условный оператор:
if age >= 18:
    print("Совершеннолетний")
elif age >= 14:
    print("Подросток")
else:
    print("Ребёнок")

Цикл for — перебирает все элементы последовательности:
for i in range(10):
    print(i)

Цикл while — выполняется, пока условие истинно:
count = 0
while count < 5:
    count += 1

Операторы: break (выйти из цикла), continue (перейти к следующей итерации).

=== 3. Функции ===

def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

print(greet("Иван"))         # Привет, Иван!
print(greet("Мария", "Здравствуй")) # Здравствуй, Мария!

Функции — объекты первого класса: могут передаваться как аргументы и возвращаться из других функций.

Лямбда-выражения (анонимные функции): square = lambda x: x ** 2

=== 4. Объектно-ориентированное программирование ===

class Student:
    def __init__(self, name, group):
        self.name = name
        self.group = group

    def study(self):
        return f"{self.name} учится в группе {self.group}"

s = Student("Иван", "ИС-21")
print(s.study())

Три кита ООП:
- Инкапсуляция — объединение данных и методов в одном классе
- Наследование — новый класс наследует свойства и методы родительского
- Полиморфизм — один интерфейс, разные реализации

=== 5. Обработка исключений ===

try:
    x = int(input("Введите число: "))
    result = 10 / x
except ValueError:
    print("Это не число!")
except ZeroDivisionError:
    print("Нельзя делить на ноль!")
finally:
    print("Готово")

=== 6. Модули и пакеты ===

Модуль — файл .py. Пакет — папка с файлом __init__.py.
Импорт: import math, from math import pi, from math import sqrt as sq.
Менеджер пакетов pip: pip install requests, pip list, pip freeze > requirements.txt.

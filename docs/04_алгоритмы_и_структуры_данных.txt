Лекция 4. Алгоритмы и структуры данных

Кафедра информационных технологий

=== 1. Понятие алгоритма ===

Алгоритм — конечная последовательность точно определённых действий для решения задачи.

Свойства алгоритмов:
- Детерминированность — однозначность шагов
- Конечность — завершается за конечное число шагов
- Массовость — работает для множества входных данных
- Результативность — выдаёт результат

=== 2. Сложность алгоритмов ===

O-нотация (big-O) описывает верхнюю оценку сложности:
- O(1) — константная (доступ к элементу массива по индексу)
- O(log n) — логарифмическая (двоичный поиск)
- O(n) — линейная (перебор массива)
- O(n log n) — квази-линейная (быстрая сортировка, сортировка слиянием)
- O(n²) — квадратичная (пузырьковая сортировка)
- O(2^n) — экспоненциальная (перебор всех подмножеств)

=== 3. Основные структуры данных ===

Массив — набор элементов одного типа, доступ по индексу за O(1).
Список (linked list) — связанные узлы, вставка в начало за O(1), поиск за O(n).
Стек (stack) — LIFO, «последним пришёл — первым вышел». Операции push и pop.
Очередь (queue) — FIFO, «первым пришёл — первым вышел». Операции enqueue и dequeue.
Хеш-таблица — быстрый доступ по ключу в среднем за O(1).
Дерево — иерархическая структура. Бинарное дерево поиска даёт поиск за O(log n) в среднем.
Граф — множество вершин и рёбер. Применяется для моделирования сетей, маршрутов, зависимостей.

=== 4. Алгоритмы сортировки ===

Пузырьковая сортировка (Bubble Sort):
- Сложность: O(n²)
- Простая, но медленная

Сортировка вставками (Insertion Sort):
- Сложность: O(n²) в худшем случае, O(n) на почти отсортированных данных

Быстрая сортировка (Quick Sort):
- Средняя сложность: O(n log n)
- Худшая: O(n²)
- Использует стратегию «разделяй и властвуй»

Сортировка слиянием (Merge Sort):
- Сложность: O(n log n) всегда
- Стабильна, но требует дополнительную память

=== 5. Поиск ===

Линейный поиск: перебор всех элементов, O(n). Работает на любых данных.
Двоичный поиск: O(log n). Требует отсортированный массив. На каждом шаге отбрасывает половину.

Алгоритмы на графах:
- Поиск в ширину (BFS) — обход по уровням
- Поиск в глубину (DFS) — обход вглубь
- Алгоритм Дейкстры — кратчайший путь во взвешенном графе
- Алгоритм A* — эвристический поиск пути

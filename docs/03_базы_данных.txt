Лекция 3. Базы данных и SQL

Кафедра информационных технологий

=== 1. Основные понятия ===

База данных (БД) — организованная совокупность данных, хранящаяся в электронном виде.
СУБД (система управления БД) — программное обеспечение для работы с БД.

Популярные СУБД: PostgreSQL, MySQL, MariaDB, SQLite, Oracle, MS SQL Server.
Нереляционные (NoSQL): MongoDB, Redis, Cassandra, Elasticsearch.

=== 2. Реляционная модель ===

Данные хранятся в таблицах. Таблица состоит из строк (записей) и столбцов (полей). Каждая строка представляет один объект, каждый столбец — атрибут объекта.

Ключевые понятия:
- Первичный ключ (PRIMARY KEY) — уникальный идентификатор строки
- Внешний ключ (FOREIGN KEY) — ссылка на строку в другой таблице
- Индекс — структура для ускорения поиска
- Схема — описание структуры таблиц и их связей

=== 3. Нормализация ===

Нормализация — процесс организации данных для устранения избыточности и аномалий.

Нормальные формы:
- 1НФ: все атрибуты атомарны (нет списков в ячейках)
- 2НФ: 1НФ + все неключевые атрибуты зависят от полного первичного ключа
- 3НФ: 2НФ + нет транзитивных зависимостей

=== 4. Язык SQL ===

SQL (Structured Query Language) — стандартный язык запросов к реляционным БД.

Основные команды:

SELECT — выборка данных:
`SELECT name, group FROM students WHERE age > 18 ORDER BY name;`

INSERT — вставка данных:
`INSERT INTO students (name, group) VALUES ('Иванов', 'ИС-21');`

UPDATE — обновление данных:
`UPDATE students SET group = 'ИС-22' WHERE id = 5;`

DELETE — удаление данных:
`DELETE FROM students WHERE id = 5;`

Соединения таблиц (JOIN):
- INNER JOIN — только совпадающие строки
- LEFT JOIN — все из левой таблицы + совпадающие из правой
- RIGHT JOIN — все из правой + совпадающие из левой
- FULL OUTER JOIN — все строки из обеих таблиц

=== 5. Транзакции и ACID ===

Транзакция — логическая единица работы, которая выполняется полностью или не выполняется вообще.

Принципы ACID:
- Atomicity (атомарность) — всё или ничего
- Consistency (согласованность) — база переходит из одного корректного состояния в другое
- Isolation (изоляция) — параллельные транзакции не влияют друг на друга
- Durability (долговечность) — подтверждённые изменения сохраняются даже при сбое
